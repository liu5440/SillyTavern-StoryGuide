# 酒馆剧情指南

在 SillyTavern 里读懂角色的故事。中文界面，支持从角色卡与世界书整理事件、地点和路线；没有世界书时，也可以创作一段带选择与结局的故事。

当前版本：**0.5.3**。构建产物已随仓库提供，安装不需要 Node 构建、独立网站或额外后台。已通过当前模型连接的小规模路线示例实测，整本世界书效果仍待验证；当前验证范围见 [验证记录](docs/verification.md)。

## 能做什么

查看 [更新日志](CHANGELOG.md) 了解每版新增与修复，查看 [版本说明与更新方法](VERSION.md) 确认当前版本、兼容范围和升级步骤。

- 选择角色资料、内嵌与关联世界书，解析原有故事。
- 没有世界书时，输入意向创作章节、事件、分支与结局。
- 查看中文事件列表、地点索引和可缩放、可拖动的路线图。
- 编辑事件及连线，核对原文依据；锁定节点、局部重生成并预览修改。
- 区分原文明确、模型推断、原创故事与用户设定。
- 默认隐藏未来事件，主动开启完整攻略后编辑、查看来源。
- 采用故事后手动记录当前事件、完成状态、选择与简单变量，并可撤销。
- 保存不同版本、导入导出故事与本局备份。

本版是玩家的剧情手册：**采用不会自动发送聊天、改写角色卡或强制模型按路线生成**。互动建议目前根据可见事件本地生成，不会额外调用模型。剧情条件由玩家判断。

## 安装到酒馆

使用以下公开仓库地址安装：

```text
https://github.com/liu5440/SillyTavern-StoryGuide
```

1. 打开 SillyTavern → 扩展 → 安装扩展。
2. 粘贴上方 GitHub 仓库地址。
3. 点击“只给我安装”，刷新酒馆页面。
4. 点击聊天输入框旁的扩展（魔杖）按钮 → **剧情指南**；也可在扩展设置展开 **剧情指南 → 打开剧情指南**。

发布与更新操作见 [GitHub 发布说明](docs/publishing.md)。

已安装的用户在“管理扩展程序”中更新并刷新即可，**无需先卸载重装**。“目录已存在”、无法更新或删除时，参见 [更新与卸载排查](docs/troubleshooting.md)。

也可先手动安装：将 `manifest.json`、`style.css` 和整个 `dist` 目录放到：

```text
SillyTavern/data/default-user/extensions/story-guide/
├── manifest.json
├── style.css
└── dist/
    └── index.js
```

多用户环境请将 `default-user` 换成对应账号目录；不要覆盖同名的其他扩展。无需复制 node_modules 或运行 npm。具体酒馆部署目录可能不同。

## 开始使用

1. 打开一个单角色聊天，再打开剧情指南。
2. 确认资料范围，选择“解析原设定”或“创作新故事”。禁用条目默认不选。
3. 需要时填写故事意向，然后生成草稿。生成会使用酒馆当前模型连接，所选资料会发给该模型服务。
4. 开启“完整攻略”，审阅事件、来源和路线图。没有固定路线的资料不会强行生成作者结局。
5. 保存草稿或采用故事，再在事件详情中记录本局进度。
6. 日常游玩关闭完整攻略，查看当前可见事件及互动方向。

生成不会覆盖旧存档；局部修改需另存版本。相同角色的不同聊天分别记录进度，刷新可恢复。聊天被修改、删除或切换分支后需要重新核对进度。

## 场景素材库

打开角色聊天 → 剧情指南 → 顶部「场景素材库」。不需要先生成故事。

- 内置16条成年角色的非露骨恋爱创作素材，分服装、姿态、互动、场景；支持搜索、分类、收藏和复制。复制不会发送聊天或修改输入框。
- 点击「整理粘贴的对话」，填写来源名称、粘贴对话，选中片段后点「使用选中片段」，补充标题、分类、描述和开场，预览后保存。原文摘录与用户改编分开标记，可回看选区和完整粘贴原文。此过程不调用模型。
- 个人素材与收藏按账号、角色隔离，同角色跨聊天共享；最多200条个人素材。所有素材仅在当前浏览器保存，清理站点数据会丢失。
- 「导出素材备份」导出JSON留存，包含个人素材的完整来源原文与收藏；本版尚不支持素材备份自动导入，可从JSON中复制文本重新整理。故事导入入口不接收素材文件。

### 从当前聊天整理与导出（0.4.0）

剧情指南 → 场景素材库 → **从当前聊天整理**。默认选择最近50条的范围，可修改起止序号，点「预览当前范围」后勾选消息。系统和空消息不参与。

点击「用当前模型整理」会通过酒馆已有模型连接发送所选消息，无需另填API密钥；本扩展不主动附带其他消息、角色卡或世界书，宿主及其他插件可能按各自设置处理提示。一次最多选择50条消息，每条最多20000字符。总字数超过12000时自动分批，每批最多12000字符，无需手动拆分；开始前展示预计调用次数，执行时显示批次进度。

模型每批最多返回8条非露骨素材草稿（整个任务最多保留200条），逐条检查原文摘录。可编辑标题、分类、描述和开场，再勾选保存；AI归纳与原创开场不等同于原文事实。来源记录聊天标识、消息序号和保存时原文快照。保存采用原子事务，失败不会留下半批条目。

支持取消及每批180秒超时；某批失败停止后续调用，已完成草稿标记为部分完成，可先保存或导出。关闭窗口、切换聊天或修改消息后旧结果不能再保存，需要重新预览。取消后底层请求仍可能继续和计费，结束前不能再发起新请求。此功能尚未验证实际模型服务输出质量与多模型兼容性；模拟模型流程与真实宿主聊天读取已分别测试，见验证记录。

### 按角色保存与导出聊天剧情归档

- 在消息预览后点击「保存聊天归档」或「导出所选聊天JSON」，可直接保留完整所选原文，不用调用AI。
- AI整理后也可保存/导出原文及当前勾选、编辑后的结果，记录完整或部分完成状态。
- 素材库 →「聊天剧情归档」可查看当前角色已保存归档、导出JSON或删除。每账号每角色最多50份，保存在当前浏览器。
- 归档格式包含角色标识、聊天标识、messages原始消息、materials整理结果和批次完成状态，方便其他工具管理；不会改动原聊天或角色卡。本版不提供归档导入。字段说明见[聊天剧情归档格式](docs/chat-archive-format.md)。

## 存储与模型说明

- 故事保存在当前站点、当前浏览器的 IndexedDB，按酒馆账号和角色隔离；不自动同步酒馆服务器或其他设备。清理浏览器数据会删除存档，请导出备份。
- 角色卡与所选世界书可能发送给当前模型服务；不读取或保存 API 密钥，无遥测，无运行时 CDN。
- 取消或超时会丢弃结果、停止后续批次；酒馆底层请求可能继续执行和计费，结束前不能再发起新生成。
- 模型输出必须经过结构和来源检查；引用文本存在不代表模型一定准确理解，仍需玩家审阅。
- 默认关闭完整攻略时，分支文字和条件也保守隐藏，防止条件描述泄露秘密。
- 不支持群聊、自动剧情推进、循环路线、复杂脚本条件或自动判断模型是否跑偏。

## 开发

建议 Node.js 22 或 24。

```sh
npm ci
npm run check
npx playwright install chromium
npm run test:browser
```

`check` 执行类型检查、ESLint、单元测试及构建；`dist/index.js` 必须提交 Git，否则酒馆用户无法直接安装。`npm run format` 统一格式。

本机 Chromium 已安装但不在 Playwright 默认位置时，可通过 `CHROMIUM_PATH` 指定可执行文件。真实酒馆测试脚本只应针对独立测试数据根运行：`node scripts/smoke-tavern.mjs`，默认测试端口 8001，需预先安装本扩展，不会调用模型。

### 无AI资料目录与流式兼容（0.5.0）

已有资料可点击“建立本地资料目录（无需AI）”，直接以卡片查看原文、保存和导出草稿，不调用模型。目录没有自动路线连线，新建后直接显示条目；自然语言事件关联可另行编辑或选择AI归纳。

普通聊天流式正常、后台整理为空时，在顶部将“模型调用方式”改为“兼容调用（跟随酒馆流式设置）”，保持酒馆流式开关开启，再提交。聊天素材整理也沿用该选择；当前页面有效，刷新后回到原方式。兼容方式复用酒馆参数构造和SSE解析，使用当前连接及模型，单次请求6000 token输出预算（与原生后台一致），不修改酒馆全局回复长度；可能增加单次用量。仅请求一份结果，不写聊天或概率缓存，不自动重试。实际中转是否恢复需真实连接验证。

0.5.1修复本地目录被剧透规则整体隐藏的问题。新建目录后直接显示资料条目，保存刷新后仍可见；0.5.0已保存的旧目录可勾选“完整攻略”查看，或重新建立目录，不自动修改旧存档。

0.5.2：解析模式显示“AI分析事件与路线”；建立本地目录后自动切到解析模式，直接点击此按钮即可让AI归纳所选原资料的先后与分支。普通聊天流式正常时，请先在顶部选择兼容调用。模型明确依据与推断仍分开标注，不声称知道原文未写明的作者隐藏路线。
