# 场景素材库实现计划

目标：FR-09，在现有酒馆扩展中提供成年角色的非露骨恋爱素材，供选择、收藏和复制。

方案：复用原生弹窗与 IndexedDB records，内置原创卡片随 bundle 发布。用户粘贴对话并手动选择片段整理；不调用模型，不自动读取聊天，不将片段当作角色原设定。

边界：不改变故事、进度或聊天输入；无新依赖。保留原目录未提交的 story.ts。收藏与个人条目按账号、角色隔离，跨聊天共享。对话文本最多 20000 字符，摘录最多 2000 字符、个人条目最多 200、收藏最多 500。

- [x] 领域：卡片分类、来源契约、可定位摘录、校验、搜索与复制文本；先验证无效来源与超限拒绝。
- [x] 存储及应用：复用事务完成语义，每条素材独立键，收藏独立键，避免整库覆盖；验证账号角色隔离及旧故事不受影响。
- [x] UI：独立素材库弹窗，分类搜索、收藏、复制、对话选区预览保存及个人条目删除；纯文本渲染，错误可见，切聊天关闭。
- [x] 发布：0.2.0，完整 check 和浏览器回归，真实宿主更新/加载检查，再推送已授权仓库。

验收：不生成故事也能打开；复制不发消息；收藏刷新恢复；对话选区能回看出处；脚本文本不执行；切角色不串库；失败不显示保存成功。

执行记录：领域/存储/浏览器新增测试先运行并观察缺失功能失败，再实现并通过。真实宿主初始化问题与产品挂载问题分别修复；独立审查无P1/P2。产品范围沿用用户已确认的非露骨素材方案，未改动原目录用户文件。
