# Galgame P0 实施计划

**Goal:** 在现有扩展中完成资料/事件分离、可信关系、可保存手动路线、桌面工作台与移动阅读及核心场景素材闭环。

**Architecture:** 旧故事及原文归档不原地迁移；新增独立 v2 资料库领域与持久化，工作台消费纯领域用例。现有宿主适配及素材管线渐进扩展。

**Tech Stack:** TypeScript strict、Zod、IndexedDB、原生 DOM/SVG、node:test、Playwright。

**Spec:** ../../galgame-product-plan.md

## 约束与执行分工

用户已授权开始实施及多智能体分工。本工作区保留上一轮未提交的产品文档；当前功能使用 codex/galgame-p0 分支，不发布、不推送、不操作用户游玩窗口。

- [x] library_domain：新增 library 领域、纯用例、独立存储、v1保守迁移、重导入差异及测试。
- [x] workspace_ui：工作台入口、三栏及移动视图、手动编辑/连接/保存/交换、浏览器验收。
- [x] scene_materials：核心场景提取与人工编辑、兼容旧素材、原文引用及测试。
- [x] 主智能体：宿主坏条目容错、契约同步、集成检查、修复及最终审查。

## 核心验收与检查

高风险领域与存储先写失败测试再实现。分别验证：无事件资料可保存、人工边不要求原文但原作边必须有证据、未确认不入正式图、共享事件及独立布局、原文变化不覆盖人工、旧版及原文归档可恢复、保存失败与上下文切换。

浏览器验证桌面闭环与360/390/430宽度手机单栏、表单连接、刷新恢复；Mock与真实宿主证据分开。集成后执行类型检查、lint、相关单测、构建和浏览器回归，根据结果补齐不兼容。既有功能不能用删测试制造通过。

## 决策记录

- 新增 v2 资料库先与 v1 并存，避免不可逆迁移；从旧故事导入明确标出未审核内容。
- P0 不新增 AI 自动路线或自动进度；不将空世界书或无关系结果视为失败。
- 手机优先阅读，但表单编辑保存完整可用；三栏只用于足够宽度。
- 当前分工在互不冲突文件并行实施，共享API先冻结，最终由主智能体集成验证。

## 实际执行记录

领域、UI、素材三组实施后完成独立审查及主代理集成。审查发现并修复：资料人工改写仍标原作、标准化及诊断键超限导致好条目失败、草稿引用缺校验、playable完整性缺校验；均补先失败后通过测试。浏览器修复更多菜单遮挡重试、切角色收起菜单的测试适配，以及真实宿主html transform导致恢复浮球视口外的问题。

验证命令、数量及真实宿主范围见 ../../verification.md 的0.7.0候选记录。保留已存在的产品文档修改，无Git提交或推送；构建产物由当前工作区生成。

保留限制：资料初次导入先人工分类及建事件，不新增AI自动路线；新场景提示词真实模型质量、手机软键盘、大图性能待验证。场景拆分/合并没有专用批量操作，现可人工分别整理及跨消息提取；不将其写成已实现。
