# 真实酒馆资料整理改进

关联 FR-02/04/06/08；用户已授权继续开发并要求独立浏览器真实验证。

## 设计与范围

真实8000酒馆的角色同时绑定内嵌及外部世界书，去重读取84条、保留出处的工作台165条。保留快照是正确行为，但逐条列表使整理重复。采用纯展示折叠，不改变导入、来源、事件和路线实体，不迁移旧数据。原作明确、标题仍为原始来源名且仅关联一个快照的资料，全文、禁用状态、分类、摘要、审核和来源类型一致时可折叠；不用标题、人物、相似度或仅内容指纹判断相同。空原文、改名及人工正文保持独立；仅人工分类不阻止折叠。展开可访问每个原始资料及出处。

批量分类是人工明确选择后修改分类，不修改摘要、来源、证据或审核，不创建事件。勾选组表示选择该组全部成员，搜索变化清空选择，筛选后全选仅作用当前可见组。一次领域操作校验全部ID和分类，任一无效全部拒绝。详情未应用输入仍保护；保存沿用工作台并发及备份。

## 实施步骤与验收

1. 先写领域失败测试：完全一致折叠、指纹碰撞不折叠、人工修改不折叠、批量分类原子性及证据保护。
2. 新增domain/material-groups.ts与application/material-classification.ts，工作台只处理选择和展示。
3. 浏览器测试资料分组、逐来源详情、批量分类保存刷新及390px布局。只跑相关单测/浏览器文件，加类型检查与相关lint、构建。
4. 独立浏览器在真实8000读取现有资料，不发消息不调用模型；开发构建先在独立8001测试根验证写入，不覆盖用户资料。记录环境、结果、未解决问题与复现步骤，不将Mock当作宿主验证。

聊天到事件/进度候选仍为后续P2，本轮优先解决真实世界书整理阻塞；不因本次分类扩展自动推进或反写世界书。
