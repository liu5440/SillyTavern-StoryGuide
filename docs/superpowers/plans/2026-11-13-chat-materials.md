# 当前聊天AI整理计划

目标：FR-10，复用当前酒馆模型，选择消息后生成非露骨素材草稿，核对来源并手动保存。

方案：新增聊天领域契约与AI模板；宿主适配只读当前chat；独立应用控制器处理捕获、在途请求、结果校验与保存，UI不请求模型。复用当前素材数据库并添加可选来源元数据，不引入依赖。

- [x] 先写领域/应用/存储测试并观察失败：范围、系统消息、错引用、选中范围、取消/旧结果、批量原子性。
- [x] 实现宿主只读接口、纯逻辑解码、模板及应用控制器，经过校验才生成草稿。
- [x] 实现消息预览、勾选、调用/取消、可编辑结果和手动保存，补浏览器流程与失效测试。
- [x] 更新0.3.0清单、README、更新日志及版本说明；执行check、浏览器与真实宿主只读验证，区分Mock模型与真实模型证据。
- [x] 独立审查并修复，中文提交，推送现有仓库，再验证公网更新。

约束：默认20条预览；提交50条/12000字符；最多8条素材；180秒超时；全部纯文本；不自动发消息/写原聊天/扫描其他聊天；空结果明确提示；保留已有功能与用户工作。

执行记录：新增测试先失败再实现，独立审查问题补充复现并修复。29项单测及10项浏览器通过，真实宿主仅验证读取与预览，未调用真实模型。取消与来源检查保持至数据库提交点。
