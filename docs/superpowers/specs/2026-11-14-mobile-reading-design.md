# 移动端阅读排版（FR-06）

用户明确要求按移动端适配处理、手机长宽比例，授权重新排版。沿用手册深蓝底#19202b、面板#222d3b、正文#ecedf0、次级文字#b0bdcb、金色#e2bf78与边线#435167；中文无衬线正文，标题19px、正文14px、注释12px。重点从管理控件转为角色资料阅读。

顶栏：角色名与收起、关闭。底栏：阅读、资料设置、更多。中部单独滚动：故事标题、折叠故事操作、四个阅读页签、人物选择、搜索与正文。工具/模型/日志入口放更多菜单，人物分类在阅读模式使用select，管理模式保留多选chips。

桌面窗口最大400×820，短屏按高度收窄保持细长比例；窄屏窗口宽视口减16，高视口减140，仍保留聊天输入区域。不改模型、来源、存档与发送行为。真实手机软键盘仍需设备实测。
