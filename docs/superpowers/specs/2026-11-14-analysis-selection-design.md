# 分析资料交互修正

用户已确认：仅展示当前卡关联的世界书；资料按子角色与公共资料分类，支持组内及全部批量勾选；人物设定没有事件也保留；AI推断与原文事实分开，引用错误不伪造。

采用现有侧栏的分组选择，不新建独立管理页。全量世界书选择会混入无关卡片，继续平铺列表会让批量操作困难，因此均不采用。关联范围包括内嵌书、主绑定书、额外绑定书及当前聊天绑定书。

分析结果保留本地原文资料卡，AI只补充事件与推断关联。引用不匹配的结果降为显式标记的待核对推断，并去掉无效引用；其他结构错误仍校验失败，不将错误结果当成功。失败响应正文单独留在页面内存供主动查看，不进入普通诊断导出，不自动发送。

不改写角色卡、世界书、聊天、模型或预设。真实模型拒绝不通过绕过预设解决。独立浏览器使用8001测试数据，避免影响用户8000游玩。
