# 0.1.0 验证记录

日期：2026-11-13。初版实现，不宣称所有需求和模型兼容性已经完成验证。

## 已执行

- `npm run check`：TypeScript strict、ESLint、16 个单元测试、esbuild 构建通过。
- `npm run test:browser`：3 个 Chromium 测试通过。覆盖模拟模型的无书创作、图展示、无剧透、安全文本渲染、采用、进度、刷新恢复、窄屏、切聊天关闭旧编辑器。
- 真实 SillyTavern 1.19.0（本机 release 06bde939f）在独立 `.local/tavern-data` 数据根、8001 端口启动。
- 将清单、样式及 bundle 安装到测试账号的扩展目录，原生加载成功。
- 通过真实宿主接口创建测试角色和测试世界书；扩展读到人物、问候与世界书事件共 3 条来源，重复内嵌条目去重；页面无未捕获异常。
- 生成结果、引用、取消、跨目标结果、存档账号/角色/聊天隔离、错误备份版本均有自动测试。
- 独立代码审查后修复旧弹窗跨聊天污染、异步保存结果覆盖、备份格式识别及边条件剧透问题，并补充回归测试。

测试页面没有使用用户真实角色卡或模型密钥。浏览器夹具中的固定故事只用于测试，不会随生产扩展提供为真实生成回退。

## 尚未验证

- 实际模型服务返回的故事质量、长世界书、多模型结构化输出兼容及费用。
- GitHub 公网仓库安装、更新及私有仓库认证；当前没有实际远程地址。
- 多用户服务器中切换账号的全流程（账号键隔离已单元覆盖）。
- 200 节点/300 边性能目标、所有浏览器与设备、浏览器配额耗尽的实机行为。
- 自动剧情推进、聊天提示注入及自动偏离检测不在本次交付内。

## 范围与限制

- 事件列表保留资料中的时间表达；未知日期不强行排序。路线图表达已明确或玩家编辑的衔接，不能视为完整自然语言剧情执行器。
- 条件说明人工判定；变量可记录，不自动影响图边解锁。
- 局部重生成保持原节点 ID、类型和所有连线；锁定节点拒绝请求。模型回复无效时提示失败，不强行替换。
- 部分批次失败保留独立部分结果版本；重试使用正常生成入口，暂不提供精确从失败批次续传的按钮。
- 原文摘录能验证存在，语义是否支持推断仍需玩家审阅；不宣称消除幻觉。
- 本局进度保存在对应故事版本下，另存或采用新版本会建立新的进度；旧版仍可在存档列表中查看。
- 数据在浏览器本地；清理站点数据、换设备或更换站点地址需要导出备份。
