# 更新与卸载排查

功能更新通过酒馆的扩展管理器完成，不要求先卸载剧情指南。这里列出排查路径；具体原因需要结合酒馆提示与服务端日志判断。

## 获取新功能

1. 关闭剧情指南及其子窗口。
2. 打开酒馆顶部的扩展设置 → **管理扩展程序**，找到 **酒馆剧情指南 / SillyTavern-StoryGuide**。
3. 执行该扩展的更新操作，成功后刷新酒馆页面。
4. 对照 [版本说明](../VERSION.md) 检查版本；仍显示旧界面时可强制刷新页面。不要清除站点存储，故事与素材保存在其中。

“安装扩展”用于首次安装。已经安装后再次向此入口粘贴同一URL，不等于更新，可能返回 `Directory already exists`（目录已存在）。此时应回到扩展管理器更新，无需为此先删除原扩展。

## 删除扩展

在扩展管理器中找到本扩展，执行删除并确认，操作结束后刷新。删除前可以导出重要故事与素材留存。剧情指南本身没有阻止卸载的逻辑，也不会在后台重新下载自己。

卸载代码与清除浏览器存档是两件事。本扩展没有自动删除IndexedDB的卸载钩子；不要为修复更新问题而先清除浏览器数据。

## 按提示定位

| 提示或现象 | 应检查的内容 |
| --- | --- |
| `Directory already exists` / 目录已存在 | 是否在“安装扩展”中重复安装；改用扩展管理器的更新操作 |
| 更新成功但界面仍旧 | 是否刷新页面；扩展管理器版本号是否已更新；是否同时安装了多个副本 |
| 403 / 无权限 | 是否为全局安装、当前账号是否有管理员权限；由有权限的管理员操作 |
| 404 / 目录不存在 | 管理器记录的目录是否已经移除，刷新后重查；不要反复删除其他同名目录 |
| 500 / Internal Server Error | 查看运行酒馆的终端日志，确认Git网络、仓库状态、文件权限或占用等实际错误 |
| 没有可用的更新操作 | 确认是否通过Git URL安装；手工复制/ZIP安装可能没有Git仓库元数据 |

上述为按现象排查的方向，不表示已经确认用户环境的原因。请保留完整提示文字、酒馆版本、安装方式（Git URL还是手工复制）以及对应服务端错误；不要提供API密钥或私人聊天原文。

## 已验证范围

2026-11-13，在独立的 SillyTavern 1.19.0 测试数据根，对0.3.0执行更新、删除及重新安装：三个接口均返回HTTP 200，删除后确认扩展目录消失，重装刷新后入口恢复。此结果证明该测试环境可正常维护，不代表已经复现或解决其他环境的删除失败。详情见 [验证记录](verification.md)。
